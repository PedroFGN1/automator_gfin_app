📖 Instruções para Correção de Erro

Erro detectado no processamento

Verifique os pontos abaixo antes de clicar em "Continuar":

1. Verifique o Terminal
  • O terminal deve estar na tela correta e pronto para receber comandos. (Visualizar tela)
  • Certifique-se de que não há mensagens de erro na tela
  • Verifique se o foco está no campo correto
2. Dados da Planilha
  • Confirme se os dados da linha atual estão corretos
  • Verifique se os códigos END e SEQ estão no formato esperado
  • Certifique-se de que o valor e data estão corretos
3. Ações Recomendadas
  • Se necessário, ajuste manualmente a tela do terminal
  • Corrigir dados incorretos na planilha se identificados
  • Clicar em "Continuar" apenas quando tudo estiver pronto

Limite de tentativas: O sistema permite até 3 tentativas por linha. Após isso, pula automaticamente para a próxima.
